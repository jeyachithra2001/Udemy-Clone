# 🎓 Udemy Clone

A simple **Udemy landing page clone** built using **HTML and CSS**. This project recreates the main layout and visual structure of Udemy's website while practicing modern CSS **Flexbox** concepts.

## 🚀 Features

* **Navbar**

  * Udemy-style logo
  * Search bar
  * Navigation links

* **Udemy Menu**

  * Clone of Udemy's category/menu section

* **Recommended Courses**

  * Course showcase with images
  * Course titles and details
  * Course information displayed in a clean layout

* **Recommended Topics**

  * Displays popular learning topics

* **Popular Courses**

  * Courses displayed based on ratings and reviews
  * Course cards with images and details

* **Footer**

  * Udemy-inspired footer layout
  * Navigation links
  * Copyright information

## 🛠️ Technologies Used

* HTML5
* CSS3
* CSS Flexbox
